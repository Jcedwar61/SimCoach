SimCoach-Setup.exe source
=========================
simcoach.nsi     the setup wizard (NSIS 3, Modern UI 2): welcome, licence, shortcuts, install folder, progress,
                 finish ("Start SimCoach"), plus the uninstaller in Settings > Apps. Installs per user, no admin.
install.ps1      the setup steps the wizard runs with no window of their own (close a running SimCoach, get uv,
                 then Python 3.12, the packages and the offline speech recognition); their output shows in the
                 wizard's progress list.
art\             the wizard's sidebar (164x314) and header (150x57) images, 24-bit BMP.

To rebuild: tools/installer/build_installer.sh (needs makensis and 7z: apt install nsis p7zip-full, or the
Windows versions). It takes the version from sim_coach.py, builds SimCoach-Setup.exe and checks every file inside
it matches the repo. Run "SimCoach-Setup.exe /S" to install silently.
